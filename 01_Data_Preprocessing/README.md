# 📊 Data Preprocessing

Data Preprocessing is one of the most important steps in the Machine Learning pipeline. It involves cleaning, transforming, and preparing raw data before training a machine learning model. Proper preprocessing improves model performance and ensures better predictions.

## 📖 Description of Each Topic

### 🟢 Missing Value Imputation
Learn different techniques to handle missing values such as:
- Mean Imputation
- Median Imputation
- Mode Imputation
- Constant Value Imputation

---

### 🟢 Encoding
Convert categorical data into numerical format using:
- Label Encoding
- One-Hot Encoding
- Ordinal Encoding

---

### 🟢 Feature Scaling
Scale numerical features to improve model performance.
Methods covered:
- Standardization
- Normalization
- Robust Scaling
- Min-Max Scaling

---

### 🟢 Handling Outliers
Detect and handle extreme values using:
- IQR Method
- Z-Score Method

---

### 🟢 Handling Imbalanced Data
Techniques for balancing datasets:
- Random Over Sampling
- Random Under Sampling
- SMOTE

---

### 🟢 Train-Test Split
Split the dataset into training and testing sets for model evaluation using Scikit-learn.
