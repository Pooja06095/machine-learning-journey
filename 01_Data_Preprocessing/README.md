# 📊 Data Preprocessing

Data Preprocessing is one of the most important steps in the Machine Learning pipeline. It involves cleaning, transforming, and preparing raw data before training a machine learning model. Proper preprocessing improves model performance and ensures better predictions.

## 📖 Description of Each Topic

### 🟢 Missing Value Imputation

Learn different techniques to handle missing values such as:

* Mean Imputation
* Median Imputation
* Mode Imputation
* Constant Value Imputation
* Random Sampling Imputation

---

### 🟢 Encoding

Convert categorical data into numerical format using:

* Label Encoding
* One-Hot Encoding
* Ordinal Encoding

---

### 🟢 Feature Scaling

Scale numerical features to improve model performance.

Methods covered:

* Standardization
* Normalization
* Robust Scaling
* Min-Max Scaling

---

### 🟢 Handling Outliers

Detect and handle extreme values using:

* IQR Method
* Z-Score Method

---

### 🟢 Handling Imbalanced Data

Learn techniques for balancing imbalanced classification datasets:

* Random Over Sampling
* Random Under Sampling
* SMOTE (Synthetic Minority Oversampling Technique)

---


### 🟢 Train-Test Split

Split the dataset into training and testing sets for Machine Learning model training and evaluation.

Topics covered:

- Feature and Target Separation
- Train-Test Split
- 80:20 Split
- `random_state`
- `stratify`
- Dataset Size Comparison
- Data Visualization
